mand-mobile 3.0 is a monorepo: `mand-mobile` (Vue 3 components), `@mand-mobile/core` (framework-agnostic logic core) and `@mand-mobile/styles` (styles). This page covers installation, import and local preview.

## Install

```bash
# Inside a pnpm monorepo — shares the same sources as this docs site
pnpm add mand-mobile @mand-mobile/styles

# Or a regular project
npm install mand-mobile @mand-mobile/styles
```

Requires Node.js ≥ 20 and pnpm ≥ 9.

## Import

All components are exported with the unified `Md*` prefix, either all-at-once or on-demand.

**Global registration** — fine for small projects or quick start.

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import 'mand-mobile'
import '@mand-mobile/styles/global.css'

createApp(App).mount('#app')
```

**On-demand import** — component and styles loaded separately.

```vue
<script setup lang="ts">
import { MdButton } from 'mand-mobile'
import '@mand-mobile/styles/es/button.css'
</script>

<template>
  <MdButton type="primary" round>Primary</MdButton>
</template>
```

:::note
Component styles are never inlined. Always import styles alongside components — either global `@mand-mobile/styles/global.css` or per-component `@mand-mobile/styles/es/<kebab-name>.css`.
:::

## Imperative API

Toast, Dialog and ActionSheet also expose imperative APIs, no overlay state needed:

```ts
import { Toast, Dialog, ActionSheet } from 'mand-mobile'

Toast.info('Operation succeeded')
Dialog.confirm({ content: 'Delete this record?' })
ActionSheet.create({ title: 'Choose', options: [{ text: 'Camera' }, { text: 'Gallery' }] })
```

## Preview the docs site locally

The `docs/` folder in this repo renders every component demo from `packages/vue/src` sources via Vue islands — ideal for **live preview and debugging while developing components**:

```bash
# from the repo root
pnpm install
pnpm --filter @mand-mobile/docs dev
```

Open `http://localhost:4321` and interact with every component page. Editing component sources under `packages/vue/src` hot-reloads the pages right away.

To regenerate the API tables (when components or props change):

```bash
pnpm --filter @mand-mobile/docs gen   # generate only
pnpm --filter @mand-mobile/docs build # generate + static build
```
