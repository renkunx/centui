centui 3.0 采用 monorepo 结构：`centui`（Vue 3 组件包）、`@centui/core`（跨框架逻辑核心）、`@centui/styles`（样式包）。本页带你完成从安装到本地预览的全部步骤。

## 安装

```bash
# 在 pnpm monorepo 内直接安装（推荐，可与文档站共享同一份源码）
pnpm add centui @centui/styles

# 或普通项目
npm install centui @centui/styles
```

需要 Node.js ≥ 20 与 pnpm ≥ 9。

## 引入组件库

组件统一以 `Md*` 前缀导出，支持全量或按需两种方式。

**全量引入**：适合小项目或快速开始。

```ts
// main.ts
import { createApp } from 'vue'
import App from './App.vue'
import 'centui'
import '@centui/styles/global.css'

createApp(App).mount('#app')
```

**按需引入**：组件与样式分别按需加载。

```vue
<script setup lang="ts">
import { CuButton } from 'centui'
import '@centui/styles/es/button.css'
</script>

<template>
  <CuButton type="primary" round>主要按钮</CuButton>
</template>
```

:::tip[注意]
组件样式不内嵌，使用组件前请务必引入对应样式（全量 `@centui/styles/global.css` 或按需 `@centui/styles/es/<kebab-name>.css`）。
:::

## 命令式 API

Toast、Dialog、ActionSheet 除组件形式外还提供命令式调用，无需维护弹层状态：

```ts
import { Toast, Dialog, ActionSheet } from 'centui'

Toast.info('操作成功')
Dialog.confirm({ content: '确认删除该条记录？' })
ActionSheet.create({ title: '请选择', options: [{ text: '拍照' }, { text: '相册' }] })
```

## 本地预览文档站

文档站（本仓库 `docs/` 目录）通过 Vue island 直接引用 `packages/vue/src` 源码运行组件 Demo，适合**开发组件期间实时预览与调试**：

```bash
# 在仓库根目录
pnpm install
pnpm --filter @centui/docs dev
```

启动后访问 `http://localhost:4321`，即可浏览全部组件页并与其交互。修改 `packages/vue/src` 下的组件源码，页面会热更新——改完直接看效果。

如需重新生成组件 API 表（组件增减、props 变化）：

```bash
pnpm --filter @centui/docs gen   # 仅重新生成
pnpm --filter @centui/docs build # 生成 + 静态构建
```
